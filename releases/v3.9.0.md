发布 v3.9.0：完成文档模型、分组与编辑体验升级，并整理仓库目录结构。

- 文档模型升级到 v5，支持旧文档迁移和可嵌套群组；对齐、等间距和中心对齐按操作单位处理，群组内部布局保持不变。
- 文本、图片和形状编辑继续统一：段落文本重排、图片默认等比缩放、空心图形点击穿透、圆角矩形、旋转复位等行为得到修正。
- 思维导图节点采用更紧凑的默认框，文字水平/垂直居中，并统一 10px 内边距。
- 保留图片 + 形状的相交、相减、分割；新增形状 + 形状布尔运算，结果生成可继续编辑节点的矢量 Path。
- 线宽默认值调整为 3；缩放控件移到右上角；更新中心对齐、AI 抠图、AI 脑图、轮廓转矢量、去水印和不透明度等按钮图标。
- 增强 SVG 安全导入以及 PNG/JPG/SVG 导出路径，批量图片导入继续自动成组。
- 移除 Dola 集成，保留 GPT / 豆包 / Grok 工作流。
- 仓库结构调整：扩展运行文件统一放入 `quickdraw-sidepanel/`；`tests/`、`.github/`、`docs/`、`scripts/`、`releases/` 与项目说明仍位于仓库根目录。测试、打包、发布和 GitHub Actions 路径已同步更新。

更新方式：使用 Release ZIP 时，解压后直接加载其中包含 `manifest.json` 的目录；从源码仓库加载时，选择 `quickdraw-sidepanel/`。更新已有安装前建议先导出 `.quickdraw` 项目备份，然后在扩展管理页重新加载并重开侧边栏。
