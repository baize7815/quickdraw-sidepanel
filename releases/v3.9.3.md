发布 v3.9.3：继续收紧主题、颜色、箭头与文本编辑体验，并修复本轮交互回归。

- 主题底色更新：亮主题画布改为 `#FDFDFB`，暗主题改为 `#181926`；JPG 导出背景跟随当前主题。
- 右侧颜色栏加入 6 组可循环色卡：多巴胺、浅霏、糖果、国风、复古、莫兰迪；默认第一组为多巴胺。暗主题下样式控件的可见性同步修正。
- 选择工具栏进一步精简：隐藏“组合 / 解组”按钮，仅保留 `Ctrl/⌘+G` 与 `Ctrl/⌘+Shift+G` 快捷键。
- 普通形状与 Path 的顶部工具栏统一支持填充色和描边色；颜色选择器拖动时实时预览，确认后只记录一次历史。
- 箭头新增 S / M / L / XL 头部尺寸，默认 M；只改变箭头头部，不改变线宽。虚线与点线节奏重新调整，虚线箭头头部始终保持实线。
- 文本缩放语义修复：普通文本恢复自由横纵拉伸并取消拖拽缩放的 96px 上限；段落文本继续保持文字不拉伸，但文本框现在可独立调整宽度和高度。
- 旋转柄固定为约 28px 屏幕距离，只跟随对象旋转方向，不再随对象缩放变长。
- 右侧样式面板、色卡和导出逻辑继续保持 Canvas / SVG 行为一致。

更新方式：下载 Release ZIP 并解压，加载其中直接包含 `manifest.json` 的目录；从源码仓库加载时选择 `quickdraw-sidepanel/`。更新已有安装前建议先导出 `.quickdraw` 项目备份，然后在扩展管理页重新加载并重开侧边栏。
