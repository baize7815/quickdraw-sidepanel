发布 v3.9.2：集中完善画布编辑、对象关系连线、SVG 导入与便签体验。

- 优化对象缩放与旋转：单对象拖拽缩放改为直接调整本地几何，避免描边和段落文字被非等比拉伸；旋转控制点统一到选框顶部中间。
- 文本与视图交互调整：段落文本框缩放只改变文本框宽高，不再拉伸文字；文字大小档位扩大为 16 / 28 / 44 / 64；`F` 与菜单统一为“缩放到所选内容”。
- 增强 SVG 粘贴导入：缺失 `width` / `height` 时回退 `viewBox`，兼容 `version="1.2"`、本地渐变与 `xlink` 等常见结构；暂不支持的渐变会安全降级为近似纯色，保持可编辑矢量对象。
- 重做“思维导图”按钮语义：选中任意已有对象后即可自动生成树状曲线关系线，不转换、不移动原对象；对象移动或缩放后连线自动跟随，关系线端点还可拖到其他对象重新绑定。
- 改进钢笔工具：绘制中 `Ctrl/⌘ + Z` 只撤回当前路径的最后一个锚点；曲线选择边界按真实贝塞尔极值计算，不再把控制柄包含进边界框。
- 完善填充与描边颜色逻辑：同时开启填充和描边时，普通点颜色只修改填充，`Ctrl/⌘ + 点颜色`只修改描边；自定义颜色同样遵循该规则，避免修改一个颜色时误覆盖另一个。
- 升级便签：点击画布即可创建空白便签并直接编辑；普通颜色修改文字色，`Ctrl/⌘ + 颜色`修改背景色；编辑时支持 S / M / L / XL 字号、左/中/右水平对齐以及上/中/下垂直对齐，画布显示与 SVG 导出保持一致。
- 默认颜色板更新为 11 色：`#1D1D1D`、`#4A4B7B`、`#8E86C2`、`#881A1F`、`#DB5476`、`#DD793E`、`#C4A37E`、`#98AA72`、`#F9DF9D`、`#EDF1F4`、`#FAFAFA`，并同步主色板、思维导图文字色板和默认自定义颜色。

更新方式：下载 Release ZIP 并解压，加载其中直接包含 `manifest.json` 的目录；从源码仓库加载时选择 `quickdraw-sidepanel/`。更新已有安装前建议先导出 `.quickdraw` 项目备份，然后在扩展管理页重新加载并重开侧边栏。
