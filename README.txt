v3.7.3 发行版更新

- 裁剪松手后保留框，可拖动内部移动、拖动八个控制点缩放；框内双击确认，Esc 取消。固定比例、旋转与镜像仍生效。

- 操作步骤与限制见 README.zh-CN.md，英文说明见 README.md。更新后在 chrome://extensions 重新加载扩展，再重开侧边栏或刷新画板标签页。

v3.7.0 图片编辑与矢量路径升级

- 对齐、等间距、分支整理及折叠按钮改为图标，悬停可查看功能名称。
- 选中对象后，画布顶部固定显示变换工具条：水平镜像、垂直镜像、顺时针 90° 旋转。
- 拖拽选框四角外侧的蓝色弧线可自由旋转；Shift 按 15° 吸附，Esc 取消本次旋转。角点方块仍用于缩放。
- 同时选择一张图片和一个形状/笔迹时，工具条显示相交、相减、分割。形状作为上层遮罩，填充、描边和画笔实际粗细参与计算；无色区域不参与。
  相交保留重合部分，相减去除形状覆盖部分，分割生成内外两个图片对象。成功后替换原图和遮罩，支持一次撤销恢复。
- 单选图片，左侧新增宫格切图按钮：2×1、1×2、2×2、3×3，或自定义列数 × 行数；最多 100 块。
  切片按原图像素均分，不遗漏边缘像素，保留原摆放、旋转和镜像；取消多选后可独立移动。
- 裁剪比例浮窗提供：自由、1:1、9:16、16:9、3:4、4:3、自定义宽高比（v3.7.1 起通过双击打开）。
  选定比例后，在图片内拖框保留内容，Esc 取消；旋转或镜像后仍按图片自身方向裁剪。
- 激光笔替换为钢笔（K / 6）：单击放置锚点，按住拖拽拉出贝塞尔手柄，点起点闭合，Enter 完成开放路径，Esc 取消。
  选中路径后点击顶部编辑节点图标，或切换钢笔，可拖动锚点及手柄；Alt 拖动单侧手柄，Delete 删除选中节点。
- 单选透明图片，点击左侧轮廓图标可按透明度生成独立的纯色矢量形状，保留孔洞，原图保留在左侧。
  阈值 1–255，默认 16。轮廓基于已有 OpenCV 本地处理，不上传图片，不新增依赖。
- 新矢量形状支持顶部独立填充色、描边色，以及右侧统一颜色、线宽、线型、填充和边框设置。
- 旋转、镜像和矢量路径随画板及 .quickdraw 项目保存；支持撤销、重做、复制及 PNG/SVG 导出。

实现边界

- 图片遮罩结果是透明 PNG。SVG 导出会嵌入该 PNG，不会把照片本身变成可编辑矢量。
- PNG 轮廓提取生成真正的 SVG path，但只读取透明度，不识别语义、不还原彩色内部图案。
  无透明背景的图片只能得到外框；边缘使用像素轮廓近似，半透明细节取决于阈值。
- 现有原生几何图形与新生成的钢笔/轮廓形状可编辑。外部复杂 SVG 导入仍作为图片显示，可提取其透明轮廓；滤镜、渐变、文字及嵌入图像不会自动拆成原生矢量节点。
- 钢笔提供锚点、曲线、闭合及基础节点编辑，不包含 Photoshop 的全部路径工具、自动描图及复杂路径布尔运算。
- 新图像处理单次上限为 1200 万像素、单边 16384 像素；复杂轮廓上限 2 万轮廓、20 万节点，超限会提示并保留原对象。
- 思维导图节点旋转后连接锚点跟随；连线仍保持原有自动布局规则。

以下为既有功能说明：

本版重点：

1. Mermaid 流程图
   - 底部新增 </> 按钮。
   - 粘贴 Mermaid flowchart TD / TB / LR / RL 文本后，Enter 直接生成；Shift+Enter 换行。
   - 支持常用矩形节点、圆角起止节点、菱形判断节点、圆形节点和 -->|标签| 连线。
   - 生成结果是 Quickdraw 原生可编辑对象，不是截图，可继续移动、改色、删线并导出矢量。

2. 思维导图
   - Tab：新增子节点；Shift+Tab：新增同级节点。
   - 节点上/右/下/左四边都有连接锚点，可拖到其他节点建立连线。
   - 连线可单独选择并 Delete / Backspace 删除。
   - □：真正 90° 正交直角连接；▢：圆滑曲线连接。
   - 普通左键点击色板：修改节点描边颜色。
   - Ctrl/⌘ + 左键点击色板：给选中的思维导图节点添加同色 18% 半透明填充，不改变描边。
   - 选中思维导图节点后，可在顶部文字颜色卡中修改文字颜色。

3. 文本与颜色
   - 文本为画布原位编辑，不弹输入对话框。
   - 选中普通文本后，直接点击顶部色板即可修改文字颜色。
   - 浅色画布背景固定为 #F9FAFB，PNG / SVG / PDF 背景保持一致。
   - 顶部浮动属性栏强制保持最多两行，不继续向下堆第三行；较窄窗口使用横向滚动。

4. 画布与箭头
   - 鼠标中键按住即可临时抓手拖动画布，松开恢复原工具。
   - 选中箭头后显示起点、弧度控制点、终点；拖动中间控制点调整曲率。
   - 形状、直线、箭头画完自动切回选择工具。
   - Alt + 拖动：复制并拖动。
   - Ctrl/⌘ + G：打组；Ctrl/⌘ + Shift + G：取消分组。

5. 导出
   - PNG / 透明 PNG。
   - SVG 可编辑矢量。
   - PDF 矢量打印（通过浏览器打印页保存为 PDF）。
   - 思维导图节点半透明填充、直角/圆角连线、Mermaid 节点与弯曲箭头都保留在矢量输出中。

常用快捷键：
- V / 1：选择
- M：思维导图
- Tab：思维导图子节点
- Shift + Tab：思维导图同级节点
- Ctrl/⌘ + G：打组
- Ctrl/⌘ + Shift + G：取消分组
- Ctrl/⌘ + D：复制所选
- Ctrl/⌘ + C：将所选对象复制为透明 PNG
- Alt + 拖动：复制并拖动
- 鼠标中键拖动：临时抓手
- Ctrl/⌘ + Z：撤销
- Ctrl/⌘ + Shift + Z：重做
- Delete / Backspace：删除所选对象或连线
