# Quickdraw 可视化 AI 图片编辑工作台：实施及验收计划

## 目标与设计边界
- 画板选中 1～4 张图片后打开**同一侧边栏内**的浮层编辑器；其中任意一张可设为主图，其余为参考图。不新开编辑标签页。
- 支持自由蒙版（笔刷/擦除/反选/羽化）、编号编辑点（独立指令）、目标框与参考图融合。
- 导出 clean image、annotated guide、可选 grayscale mask、可选 reference、通用提示词和 JSON 编辑配置。
- 同一主图可设置多个独立编辑点；记录原图像素坐标、归一化 [x,y] 坐标、点位 ID 和说明。全局提示词与点位说明都允许 @点1 / @图2 等引用，自动补全并编译为上传角色和位置指令。
- 工作台向 Quickdraw 的 GPT / 豆包 / Grok / Gemini 图片任务队列提交：上传主图、标注图、参考图，发送后台编译的提示词；各网站仍独立执行权限/功能检查。
- Gemini 采用**网页会话适配器**而非专门的图片编辑 API；只操作用户已授权的网页输入/上传/发送控件，不尝试绕过平台年龄或账户权限。导出和手动导入仅为备用操作。
- 提交前复制输入图片至一次性 AI 任务资源，任务完成后删除副本而非原画板图片；保护已经选择的原始资源。

## 分阶段执行
1. 保留原工作区的脏文件改动，不重置、不覆盖、不提交。
2. 创建纯逻辑提示词/坐标核心，三模式可视化界面与标记持久化。
3. 接入 Quickdraw 选中图片入口，返回图片通知及导入。
4. 添加核心单元测试，运行现有 Node 回归测试和语法检查。
5. 检查差异，只交付已验证的能力，留下受第三方服务限制的未完成项。

## 留意事项
- 原始画板对象如被裁切/旋转，工作台编辑的是**存储的原始图片像素**而非画板渲染后的投影。
- 对融合模式，模型可能在目标框以外调整阴影/反射；点模式不是像素级局部保护。
- 本地合成仍要求生成图与原图宽高比基本一致。非蒙版模式整体使用生成结果。
- 存储的会话草稿和相关图片保存在浏览器扩展自身的存储空间，完整编辑包是跨设备恢复的可读基础数据。
